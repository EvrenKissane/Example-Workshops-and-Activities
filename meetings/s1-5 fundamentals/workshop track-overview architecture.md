# **Do Quantum**: Track Overview: Architecture

# Whats
1. Abstract Theoretical Physics
2. Demonstrated Phenomenon
3. Controlled Physics
4. Systematic Implementation
5. Deployed Processor

# Hows
1. Abstract Theoretical Physics
   Is something possible?
   Does a new theory imply some effect?
   Is there a new development in metrology or sensing that allows better precision?
   Has a new characterization method been developed to evaluate principal components?

2. Demonstrated Phenomenon
   What does it?
   Does this happen more than once?
   What changes when it happens?

3. Controlled Physics
   Can we make it happen on command, and how reliable is it?

4. Systematic Implementation
   This section is often what people mean when they talk about computer architecture.
   However, architectures using physical or electrical phenomenon often outperform those that we can clearly model computationally. For example, see content-addressable memory (CAM).
   Quantum error-correction (QEC) works best when considering the designs here.

5. Deployed Processor
   Can you run a program on it?
   What resources does it need: fuel, cryo, heat, power, recalibrations, ...
   What do users need to know about it?
   How do I design benchmarks?
   Quantum error-mitigation (QEM) is for this layer.

# Notes

- Each step of the process uses information from the last, and influences the design of the next step.
  Consider how scaling works: connectivity, precision, coherence, ...

- Follow along with your favorite architecture.
  The time it takes to move through all 5 stages has been large.
  However, the major bottlenecks have been made solvable:
  technical communication, research context, documentation, computer simulations, ...
